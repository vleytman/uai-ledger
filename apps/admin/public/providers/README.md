# Provider icons

Local files identify connection types. If an image fails to load, the interface displays the first letter of the name.

- OpenAI and Anthropic: SVG files from `@lobehub/icons-static-svg@1.95.0`, [upstream project](https://github.com/lobehub/lobe-icons), MIT license.
- Cartesia: SVG icon from the Cartesia home link in the [official interface](https://play.cartesia.ai/), retrieved September 19, 2026.
- Serper: favicon from the [official website](https://serper.dev/favicon.ico), retrieved September 19, 2026.

Trademarks belong to their respective owners. The running admin interface makes no external requests to load these images.
