# Значки провайдеров

Локальные файлы используются для обозначения типа подключения. При ошибке загрузки интерфейс показывает первую букву названия.

- OpenAI и Anthropic: SVG из пакета `@lobehub/icons-static-svg@1.95.0`, [исходный проект](https://github.com/lobehub/lobe-icons), лицензия MIT.
- Cartesia: SVG-значок из ссылки Cartesia home в [официальном интерфейсе](https://play.cartesia.ai/), получен 19 сентября 2026 года.
- Serper: favicon с [официального сайта](https://serper.dev/favicon.ico), получен 19 сентября 2026 года.

Товарные знаки принадлежат соответствующим владельцам. Во время работы админки внешние запросы за изображениями не выполняются.
